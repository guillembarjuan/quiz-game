4. Components i estats

Cada component es dibuixa amb les mateixes regles CSS que l'app. Els estats hover i focus es forcen per poder-los veure sense el ratolí; també pots passar-hi el ratolí o navegar-hi amb el tabulador.

Botó · .btn i .btn--primary

Camp de text · #player-name

Opció de resposta · .btn.game-option

A l'app no hi ha un estat «seleccionada» separat: un clic respon de seguida. Per això l'estat seleccionat és el focus de teclat. El text «— Correcta» i «— La teva resposta» fa que el resultat no depengui només del color.
